# Структура застосунку (Wireframes v.2)

## Пріоритети розробки

**Основний фокус зараз (після оновлення коду):**

1. **Флоу замовлення / бронювання ліків** — **реалізовано демо-версію:** шит `OrderMedicinesSheet` (призначення, альтернативи препаратів, список аптек, перемикач список/карта), **чекаут** `/checkout` (кількості упаковок, оплата, підтвердження). Залишилось: інтеграція оплати, кошик як окремий стан, повний UX за вайрфреймом там, де відрізняється від прототипу.
2. **Карта аптек** — **частково зроблено:** окремий шит `PharmacyMapDrawer` (OSM, Київ, маркери з ціною, картка аптеки знизу, обране ❤️, перехід «Замовити» → чекаут). **Ще не зроблено:** пошук по адресі на карті, радіус/слайдер цін, фільтри «як Booking».

**Другорядні** (після або паралельно без блокування основного): підтвердження запису, `/profile`, `/services`, фільтри каталогу, вкладки «Мої візити», чат, обране, AI-підбір, наші відділення, карта до клініки тощо.

## User story (вимоги)

- Запис на прийом, мої результати аналізів, рецепт (скачати), записатись на прийом, спілкування з лікарем онлайн.
- Слоти всіх лікарів на обраний день.
- Забронювати ліки поряд з лікарнею/будинком.
- Мої візити та призначення, одна кнопка — повторити замовлення.
- Картка лікаря: ПІП, фото, скарги (з чим приймає), досвід, відгуки, рейтинг, доступні слоти.
- Лікарі з найближчими слотами — вище в списку.
- Фільтр по спеціалізації в каталозі.
- Шлях пацієнта: від філіалу клініки або від лікаря найближчого до адреси.
- Головна: акцент на «Запис на прийом» та «Невідкладна допомога».
- Якщо не знаєш, до кого йти — нейронка: клієнт описує симптоми, AI підказує до кого звернутись.

### Нижнє меню (доступ з багатьох екранів)

- **Головна** → головна сторінка (привітання, банер, кнопки).
- **Каталог лікарів** → список/каталог лікарів з картками.
- **Мої записи** → екран «Мої записи» (вкладки: Заплановані, Завершені, Скасовані; список записів; можливо блок «Мої дані»).
- **Профіль** → кабінет користувача (профіль, історія, налаштування).

Нижнє меню однакове на головній, каталозі, профілі лікаря та в «Мої записи» — ці екрани пов’язані між собою через нього.

### Екрани фільтрації (каталог)

- **Список лікарів** → кнопка фільтра → **«Фільтр лікаря»**: сортування (по замовчуванню, за ціною, по рейтингу).
- **Список лікарів** → розширений пошук → екран з полями **дата прийому**, **фільтр спеціальності**, **фільтр дати** → відфільтровані картки лікарів.

### Підсумкова схема флоу

1. **Головна** → (Записатись на прийом / Каталог у меню) → **Каталог лікарів**.
2. **Каталог лікарів** → (картка лікаря) → **Профіль лікаря**.
3. **Профіль лікаря** → (слот + Записатись) → **Підтвердження запису** → (Підтвердити) → успіх / **Мої записи**.
4. **Каталог лікарів** → (фільтр) → **Фільтр лікаря** або екран фільтрів (дата, спеціальність) → оновлений список карток.
5. Будь-який екран з нижнім меню ↔ **Головна**, **Каталог**, **Мої записи**, **Профіль** через відповідні пункти меню.

## Екрани та флоу

### 1. Головна (Home)

- Привітання: «Вітаємо, Наталіє Сергіївна!» + «змінити».
- Банер.
- Кнопки:
  - Записатись на прийом
  - Онлайн консультація
  - Каталог онлайн (опційно)
  - Здати аналізи
  - Послуги клініки
- Нижнє меню.

**Уточнити:** структуру та розміщення кнопок можливо варто побудувати по-іншому (наприклад, сітка, групування за пріоритетом, або окремий блок «Невідкладна допомога»). Потрібно узгодити з фінальним дизайном.

---

### 2. Каталог лікарів (Doctors / Записи)

- Фільтр: спеціальність.
- Фільтр: доступність по часу.
- Список карток лікарів (сортування: найближчі слоти вище).
- Додатково: фільтр адреси філіалу; блок «Я не знаю, до якого лікаря записатись» (AI-підбір).
- Нижнє меню.

### 3. Картка лікаря (список)

- Найближчий вільний слот: дата + час (наприклад, «сьогодні о 13:00»).
- Фото, ПІП, спеціальності.
- Рейтинг (відгуки), роки досвіду.
- Вартість консультації (грн).
- Кнопка «Записатись».
- Адреса прийому (наприклад, «Златоустівська, 7»).

### 4. Профіль лікаря (детальна сторінка)

- Фото, ПІП, спеціальності, онлайн-консультація.
- Блоки: «Про лікаря», «Доступні слоти», «Записатись».
- Послуги, які надає лікар.
- Рейтинг і відгуки (наприклад, 4,8 (20 відгуків)).
- Рецепт на ліки (перелік: препарат, дозування, виробник, діапазон цін, кількість в упаковці; кнопки «змінити»).
- Нижнє меню.

### 5. Підтвердження запису (Booking confirmation)

- Заголовок: «Підтвердження запису».
- Лікар: ПІП.
- Дата та час.
- Послуга (наприклад, «консультація з оглядом»).
- Тип: в клініці / онлайн.
- Адреса клініки.
- Кнопка «Підтвердити».

### 6. Мої візити

- Список візитів/записів.
- Деталі візиту, повтор запису, можливо рецепти/результати.

### 7. Кабінет / Профіль користувача

- Особисті дані, налаштування, історія, документи (результати аналізів, рецепти).

### 8. Чат (якщо в меню)

- Онлайн-спілкування з лікарем.

### 9. Обране (якщо в меню)

- Збережені лікарі або записи.

### 10. AI-підбір лікаря («Не знаю, до якого записатись»)

- Поле для опису симптомів.
- Відповідь AI: рекомендований спеціаліст/лікар.

### 11. Замовлення ліків (шит `OrderMedicinesSheet`) — зроблено (демо)

- Вхід: **деталі візиту** — **Забронювати**; **Мої візити** — **Замовити ліки** на картці візиту.
- Призначення: список препаратів з цінами (діапазон), кількість за призначенням лікаря; **Змінити** → bottom sheet **альтернатив** (`MedicationAlternativesDialog`) з бейджами (прописано лікарем / топ / найдешевший).
- Аптеки: **список** (сортування за відстанню / ціною) або **карта** (`PharmacyMapDrawer`).
- CTA на аптеці: **Замовити** → маршрут **`/checkout`** з передачею `state` (аптека + обрані варіанти препаратів).

### 12. Карта аптек (у шиті) — зроблено (демо)

- Окремий bottom sheet: тайли **OpenStreetMap**, центр **Київ**, маркери з **ціною** на піні.
- Клік по маркеру: картка **знизу від карти** (деталі, ❤ улюблена аптека — `localStorage`, закрити картку).
- **Ще планується за вайрфреймом:** пошук по адресі, радіус, слайдер ціни, фільтри як у Booking.

### 13. Чекаут (`/checkout`) — зроблено (демо)

- Картка обраної аптеки; список позицій з **кількістю упаковок** (±), **штуки** (розрахунок з демо-даних), видалення рядка.
- Повідомлення про **бронь ~2 доби**; вибір оплати: **картка онлайн** / **в аптеці**; підтвердження → екран успіху.
- **Наступні кроки:** реальна оплата, контакти з профілю, збереження кошика.

### Головна (Home)

| Елемент | Зараз | Пропозиція |

### Загальні компоненти, які варто мати

- **ScreenHeader** — назад (опційно), заголовок, права кнопка (опційно). Використовувати на MyVisits, VisitDetails, DoctorProfile, DoctorList.
- **ActionButton** — велика outline-кнопка для головної (іконка опційно, full width, більший padding). Можливий варіант: `size="block"` у Button або окремий компонент.
- **SectionTitleRow** — заголовок секції + посилання праворуч («Всі записи» тощо).
- **DoctorCard** — винести з DoctorList у окремий файл.
- **FilterChip** / **FilterToggle** — для фільтрів каталогу (активний/неактивний).
- **SlotPicker** — вибір часу слота (перевикористання на профілі лікаря та підтвердженні).

Після впровадження цих компонентів екрани стануть простішими, а стилі та поведінку можна змінювати в одному місці.
